## ✅ Prerequisites Checklist

Before running this project on a different computer, ensure the following:

- [ ] **Node.js v18.0.0 or higher** installed  
      (`node --version` and `npm --version` work in terminal)
- [ ] **Git** installed  
      (`git --version` works in terminal)
- [ ] **A modern web browser** (Chrome / Edge / Firefox – latest version)
- [ ] **Firebase / Google Cloud project** created
- [ ] **Firestore Database enabled** in the Firebase project
- [ ] **Firebase Service Account Key (JSON file)** downloaded and available locally  
      (for backend authentication with Firestore)
- [ ] **Active internet connection** (required for Firebase access)
- [ ] **At least 4 GB RAM** recommended on the system
- [ ] **Sufficient disk space** for node_modules and build artifacts

### 🪟 Optional (Windows only, for startup scripts)
- [ ] **Windows 10 or 11**
- [ ] **PowerShell 5.0+** (for running `start-prod.ps1`)
- [ ] Permission to run PowerShell scripts (Execution Policy configured if needed)

### 🧪 Optional (For development/testing)
- [ ] Ability to run Node.js scripts from terminal
- [ ] Firewall allows local ports (e.g., 3000) if restricted
